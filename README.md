## The image

A dense broadsheet that fits one day of world news on a single page:
**46 stories** in total, dated Wednesday 25 November 2026.

- **2 pictured leads:** China's Shenzhou-24 launch (Pakistan's first astronaut,
  Zeeshan Ali, aboard) and the Saudi-led coalition's strikes on Yemen's
  Hodeidah port.
- **6 pictured medium stories:** Kilmar Ábrego García self-deporting to Spain,
  NATO vowing space defence, the Cartagena supermarket hostage siege, Kim
  Yo-jong threatening Switzerland's Pyongyang office, scrutiny of Nvidia's
  board, and leaked records putting Russian war dead at 720,000.
- **38 short stories** in three columns (World / Markets / More Today),
  spanning the Americas, Europe, the Middle East, Asia and Oceania.

## The program

`main.py` (Python 3.13, standard library only) copies the finished
`entry.png` into the output directory named by `MAKEFUN_OUTPUT_DIR`
(or `/output` by default) as `entry.png`. It creates the output directory
if it is missing and never deletes it. Running it twice produces the same
bytes.
