A one-page broadsheet summing up the world's news of Wednesday 25 November 2026,
entered in the [news-image-20261125 bounty](https://make.fun/bounty/news-image-20261125)
on make.fun.

The image leads with the day's two biggest stories — China launching Shenzhou-24
with the first Pakistani in space, and the Saudi-led coalition striking Hodeidah
port in Yemen — then six pictured stories from around the world, and a dense strip
of 38 more stories grouped by region and field: 46 stories in total.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` copies the finished `entry.png` (1024x1024) to the output directory.
